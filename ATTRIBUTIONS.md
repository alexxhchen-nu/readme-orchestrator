# Attributions & Upstream Credits · 上游技能致谢与学术溯源

**English** | **简体中文**

`readme-orchestrator` stands on the shoulders of five open-source specialist README skills, an autonomous skill evolution framework (`darwin-skill`), and 29 cited documentation standards. All bundled skills in [`./bundled-skills/`](./bundled-skills/) retain their original provenance and licenses.

`readme-orchestrator` 站在 5 个专精 README 开源技能、自主技能进化引擎（`darwin-skill`）以及 29 份经典工程文档标准之上。仓库 [`./bundled-skills/`](./bundled-skills/) 目录下随附的全部专精子技能均完整保留其原始署名与开源协议。
