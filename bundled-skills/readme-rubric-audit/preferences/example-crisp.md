# README style profile — crisp

<!-- The maintainer's own profile, shared as a reusable example. Copy and change
     it freely. The standard's honesty and correctness rules always win. -->

## Tagline
- One sentence stating what it is and who it's for.
- No stacked list of attributes joined by dashes.

## About (GitHub description)
- One sentence, tagline style — same rule as the tagline.

## Voice
- Crisp, clear, plain.
- Cut every word that isn't working.

## Punctuation
- Never use em dashes. Use a comma, a colon, a period, or restructure.

## Paragraphs
- Max 2 paragraphs per section.
- Max 2 sentences per paragraph.

## Bullets
- Prefer bullets over prose.
- One sentence per bullet.
- Keep each bullet to a single line.

## Headings
- Use headings so every section is scannable.
